\section{Python}

Python ist eine weitverbreitete Programmiersprache, die von der Python Software Foundation weiterentwickelt wird. Ihr Designer ist Guido van Rossum. Die Sprache wurde in den 90er-Jahren entwickelt und hätte ursprünglich als Skriptsprache für das Betriebssystem Amoeba gedient. 1994 erschien Python 1.0. Die aktuellste Version ist 3.14.8.\todo{Quelle und Versionsnummer auf python.org prüfen} Python eignet sich für Anfänger und für Experten, weil die Sprache leicht verständlich ist und viele Libraries (Bibliotheken) hat, aber auch komplexe Aufgaben lösen kann. In Python ist jeder Datentyp ein Objekt.

\section{Libraries}

\subsection{Socket}

Die Bibliothek \textbf{Socket} stellt Verbindungen zwischen einem Server und einem Client her.\citep{SocketLowlevelNetworking,pythonSocketProgrammingPython2024} Der Begriff stammt aus dem ARPANET (Advanced Research Projects Agency Network), wo er bereits 1971 verwendet wurde. Sockets arbeiten mit TCP/IP und können dadurch eine zuverlässige Verbindung zwischen mehreren Geräten aufbauen. Die Bibliothek greift dazu auf die Transportschicht des Betriebssystems zu, das die darunterliegenden Schichten des OSI-Modells übernimmt.

\subsection{Threading}

Die Bibliothek \textbf{Threading} erlaubt es, mehrere Operationen scheinbar parallel auszuführen.\citep{ThreadingThreadbasedParallelism} Sie verhindert, dass langsame Operationen den restlichen Programmablauf blockieren, indem sie diese in separate Threads auslagert.

\subsection{Tkinter}

\textbf{Tkinter} ist eine ressourcenschonende Bibliothek für grafische Benutzeroberflächen (GUI, graphical user interface), die sich frei gestalten lassen.\citep{engineerTkinterTutorial20262023} Mit ihr baut man Fenster, die Eingaben des Benutzers entgegennehmen und weitergeben. Im OSI-Modell gehört sie zur Anwendungsschicht. Es gibt auch erweiterte Bibliotheken, die auf Tkinter aufbauen und die Oberfläche zusätzlich optisch aufwerten. In dieser Arbeit verwende ich CustomTkinter.\citep{CustomTkinterDocs}

\subsection{Pycryptodomex}

\textbf{Pycryptodomex} ist eine Bibliothek mit einer Vielzahl moderner Verschlüsselungsalgorithmen.\citep{PyCryptodomeDocs} Sie enthält denselben Code wie Pycryptodome, wird aber unter dem Namensraum \texttt{Cryptodome} installiert. Das vermeidet Konflikte mit anderen Kryptographie-Bibliotheken, die im selben Projekt installiert sind. Alle Algorithmen, die ich für die Verschlüsselung brauche, sind in dieser Bibliothek enthalten.

\section{GitHub}

\textbf{GitHub} ist eine der wichtigsten Webseiten für Entwickler im Bereich Informatik. Projekte auf GitHub sind oft transparent und Open Source, das heisst, jeder kann öffentliche Repositorys einsehen und für sich herunterladen. Code wird über Git-Commits hochgeladen. In meiner Arbeit dient das als Arbeitsjournal, weil jede Veränderung des Codes als Commit im Git-Graph erkennbar ist.
